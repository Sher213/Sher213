# 🧠 Current AI Research

I'm particularly interested in understanding **how information, uncertainty, and structure evolve inside AI systems**.

### 🔬 Functional Space Notation

A mathematical framework for representing structured datasets, neural networks, and machine-learning models as **functional state spaces**.

The goal is to provide a unified representation for studying relationships, transformations, and evolving states within computational systems.

👉 [Explore the Functional Space System](https://github.com/Sher213/FunctionalSpaceSystem)

### 🌀 Diachronic Entropy in Multi-Agent AI

Research into how information entropy evolves across sequential interactions between agents in multi-agent LLM pipelines.

The framework explores the relationship between **information, uncertainty, and agent interactions** across time.

👉 [Read my AI research](https://asher-research-site.netlify.app/papers)
